# ChillTea - Premium Tea Experience

![ChillTea Banner](https://placehold.co/1200x400/949E7A/ffffff?text=ChillTea)

> **Brewing pause in the midst of chaos.**

ChillTea is a premium tea brand website that offers a moment of tranquility through carefully crafted tea products. Built with Next.js 16 and React 19, this modern web application delivers an immersive brand experience with smooth animations and elegant design. (Because this is still an experiment, the results can be said to be still lacking. ≧ ﹏ ≦)

## About ChillTea

ChillTea was born from a simple search: the need to stop and pause. We believe that a cup of tea is not just a thirst-quenching drink, but a small ritual to reconnect with yourself.

### Our Philosophy

- **Single-Origin Selection**: Hand-picked tea leaves from specific highland plantations
- **100% Natural Extraction**: No artificial flavors, no synthetic colors, no preservatives
- **Eco-Conscious Packaging**: Biodegradable tea bags woven from plant fibers, no microplastics

## Features

- **Modern UI/UX**: Elegant design with smooth scroll animations powered by Framer Motion and GSAP
- **Responsive Layout**: Fully responsive design that works on all devices
- **Custom Loader**: Engaging loading experience before entering the site
- **Interactive Menu**: Bento-grid style product showcase with hover effects
- **Testimonials Section**: Animated customer reviews with marquee effect
- **Smooth Scrolling**: Enhanced scroll experience using Lenis

## Product Range

### Signature Collection
- Original Ice Tea
- Sweet Ice Tea

- Green Tea Ice

### Extended Menu
- Fruity Variants: Peach, Lychee, Mango, Strawberry, Passion Fruit, Apple, Orange, Grape
- Herbal Variants: Mint, Jasmine
- Milk/Matcha Series: Milk Tea Classic, Brown Sugar Milk Tea, Matcha Latte, and more

## Tech Stack

- **Framework**: Next.js 16.2.2
- **Language**: TypeScript
- **UI Library**: React 19
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion, GSAP
- **Icons**: Lucide React
- **Smooth Scroll**: Lenis

## Getting Started

### Prerequisites

- Node.js 18+
- npm, yarn, pnpm, or bun

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

### Build for Production

```bash
npm run build
npm start
```
